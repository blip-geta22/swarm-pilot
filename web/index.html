🤖 SwarmPilot

8 autonomous robots, PID steering, virtual lidar, obstacle avoidance, and flocking — all in your browser. Tune the PID live and watch the swarm react. Low Kp turns sluggishly, high Kp overshoots and wobbles.

This browser version is a simplified visualization of the same PID and avoidance logic in swarm_pilot/. It uses the same turn-rate PID with integral clamping, sensor noise, and clear-side obstacle avoidance, and it is tested headlessly in web/test_sim.js — it does not model full differential-drive wheel speeds.

How it works: each robot runs a PID controller on heading error to the target (green star). PID output is a turn rate, with angular inertia, so tuning matters. When lidar sees an obstacle ahead, the robot steers to the clear side and slows down — it goes around, and a contact pushes it out instead of letting it drive through. The Python version in this same repo (swarm_pilot/) runs the same idea headlessly, plus a genetic algorithm that evolves the best Kp/Ki/Kd automatically: python -m swarm_pilot.cli tune. See web/test_sim.js for the headless test of this exact browser physics.
